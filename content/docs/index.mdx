Highwren UI is the component library behind every web project: marketing sites, admin
panels and the panels users sign in to. Pill-shaped controls and quick, calm motion sit on neutral
surfaces, and the accent appears only where it means something.

## What it is

- **Colour roles, generated from one seed colour.** `bg-canvas`, `bg-surface-raised`,
  `bg-primary-solid`, `bg-neutral-soft`, `text-on-surface-variant`. Every role has a light and a
  dark value at three contrast levels, and the same engine themes a card or the whole page at
  runtime.
- **One variant vocabulary.** `variant` says how much ink a component uses (`solid`, `soft`,
  `outline`, `ghost`), `tone` says which role paints it (`primary`, `neutral`, `error` and the
  status tones), and `size` is `sm`, `md` or `lg` at 32, 40 and 48px.
- **Source you own.** Components install through the shadcn CLI as files in your project, from a
  registry. You change them per project and pull upstream changes with `--diff`.
- **Accessible by construction.** Interactive components are built on React Aria Components:
  keyboard support, focus management, screen reader announcements, 13 calendar systems and
  right-to-left layout come with them.
- **Your words.** The library ships no translations. Every string a component writes on its own
  is an English default you replace per component or once for the app.
- **Motion with manners.** Presses scale, indicators slide and overlays grow from their trigger in
  150 to 350ms, and every animated component honours reduced motion.

## How it is organised

| Layer       | What lives there                                                               |
| ----------- | ------------------------------------------------------------------------------ |
| Foundations | Tokens, theme, dynamic colour, `DSProvider`, icons, text and direction, motion |
| Components  | Accessible primitives and composites: buttons, inputs, overlays, tables, dates |
| Blocks      | Whole sections: app shell, settings page, sign-in, data table page             |
