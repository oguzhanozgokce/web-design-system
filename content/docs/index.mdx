Highwren UI brings useful interface patterns into one consistent React library.
It is built for marketing sites, admin tools and signed-in products: familiar controls,
quiet surfaces and motion that helps you follow the action.

## One shared language

<ComponentPreview name="button-variants" />

| You control          | The library provides                                           |
| -------------------- | -------------------------------------------------------------- |
| Brand and appearance | Semantic colours, consistent shapes and light/dark themes      |
| App behaviour        | React Aria controls, keyboard interaction and accessible names |
| Product wording      | English defaults with label overrides                          |
| Routing and locale   | A provider that connects to your app                           |
| Motion               | Shared timing and reduced-motion support                       |
