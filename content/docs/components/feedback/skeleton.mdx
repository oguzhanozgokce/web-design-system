## Usage

```tsx
import { Skeleton } from '@/components/ds/skeleton';

<section aria-label="Team members" aria-busy={isLoading}>
  <Skeleton shape="circle" />
  <Skeleton shape="text" lines={2} className="text-body-md" />
</section>;
```

Show a skeleton when the layout of the content is known and the wait is short, such as a list,
a card or a table loading its first page. For an action the person started, use the pending state
of the button instead; for a long job with a known size, use
[`LinearProgress`](/docs/components/feedback/progress).

## Examples

### Text

`shape="text"` draws one bar per line. Each line is exactly one line box tall and the bar sits in
its middle, so a skeleton with `text-body-md` takes the same height as the paragraph it stands for
and the page does not jump when the text arrives. `lines` adds lines; the last one is shorter, like
the end of a paragraph. Set the width on the skeleton for headings and short values.

<ComponentPreview name="skeleton-text" />

### Shapes

`circle` is 40px by default, the size of an avatar; `rect` fills the width and is 96px tall, with
the medium corner radius. Size both with `className`.

<ComponentPreview name="skeleton-shapes" />

### Tables

Keep the real table header and put skeletons in the cells, with widths that vary from row to row.
Admin screens feel faster when the frame of the page is already there. Align each skeleton like the
value it stands for, so amounts sit at the end under an end-aligned header, and hide the same
columns on small screens that the loaded table hides.

<ComponentPreview name="skeleton-table" />

### Wrapping content

Give `Skeleton` children and it keeps their size while `isLoaded` is false: the children render
invisible and inert, and the skeleton paints over their box. When `isLoaded` turns true the children
appear with a short fade. They stay mounted the whole time, so their state survives a reload.

The wrapper is a block `div`. Add `w-fit` to hug content that is narrower than the row, such as a
name or an amount. A `null`, `undefined` or `false` child counts as no content, so
`{invoice && <InvoiceRow invoice={invoice} />}` shows a plain placeholder until the data arrives.
Without children, a loaded skeleton renders nothing.

## API

### Skeleton

| Prop        | Type                           | Default  |
| ----------- | ------------------------------ | -------- |
| `shape`     | `'text' \| 'circle' \| 'rect'` | `'rect'` |
| `lines`     | `number`                       | `1`      |
| `isLoaded`  | `boolean`                      | `false`  |
| `children`  | `ReactNode`                    |          |
| `className` | `string`                       |          |

Every other `div` attribute is passed through.

### Styles

`skeletonStyles` exposes the slots `root`, `block`, `line` and `content`, with the variants
`shape`, `motion` (`full`, `reduced`, `none`) and `isLoaded`. The fill is
`bg-surface-container-highest` with the theme's `skeleton-shimmer` utility and `animate-ds-shimmer`.
Inside a surface of the same colour, such as a filled card, pass a different container role through
`className`.

### Data attributes

`data-slot="skeleton"`, `data-shape`, and `data-loaded` once wrapped content has loaded. Parts:
`data-slot="skeleton-line"`, `"skeleton-content"`.

## Accessibility

- Skeletons are `aria-hidden`: a screen reader should not hear a list of empty shapes. Wrapped
  children are invisible and `inert` while loading, so they cannot take focus either.
- Put `aria-busy="true"` on the region, list or table that is loading and set it to `false` when the
  content is in place. Screen readers then wait for the update instead of reading half a page.
- If the wait can be long, also say so in words: a `role="status"` message such as "Loading
  transactions", or a named `LinearProgress` with `isIndeterminate`.
- The shimmer runs from the start edge to the end edge, so it reverses in right-to-left languages.
  With reduced motion, from the operating system or `DSProvider motion="reduced"`, it becomes a slow
  pulse; `motion="disabled"` keeps the placeholders still.
- Structure is checked with axe in light, dark and RTL by `skeleton.test.tsx`.
