## Usage

```tsx
import { Badge, BadgeAnchor } from '@/components/ds/badge';

<Badge count={unread} />;

<BadgeAnchor badge={<Badge count={unread} />}>
  <InboxIcon />
</BadgeAnchor>;
```

## Examples

### Dot, count and overflow

Without `count` or children the badge is a dot that says "something new". With `count` it shows the
number in a pill: 20px tall at `size="md"`, 16px at `size="sm"`. Counts above `max` (99 by default)
read `99+`. A count of zero renders nothing unless you pass `showZero`.

<ComponentPreview name="badge-sizes" />

### Short text

Without `count`, children show a short label such as "New" or "Beta" in place of a number; when
both are given, `count` wins. Keep it to one word; longer text belongs in a
[Tag](/docs/components/data-display/tag).

<ComponentPreview name="badge-text" />

### Variants and tones

`variant="solid"`, the default, fills the badge with a strong colour that stays saturated in dark
mode. `soft` uses a pale tint of the tone with the tone as text, for counts that should not shout,
such as a total next to a navigation item. `error` is the default tone and suits unread counts;
`primary` fits totals that need no action, `success`, `warning` and `info` carry status, and
`neutral` is a dark pill in light mode and a light one in dark mode. A dot always uses the solid
fill, so it stays visible in either variant.

<ComponentPreview name="badge-tones" />

### On an icon

`BadgeAnchor` pins its `badge` to the top-end corner of its child and moves it a quarter of its own
size outwards, so a count overhangs the corner without hiding the icon. Anchored badges default to
`size="sm"`. A 2px seam in the page colour separates the badge from what it sits on; on a raised
surface, set `--ds-badge-seam` to that surface's colour on any ancestor, for example
`[--ds-badge-seam:var(--surface-raised)]`. The corner follows the reading direction, so it moves to
the left in Arabic.

<ComponentPreview name="badge-anchor" />

### On an avatar

`overlap="circular"` centres the badge on the rim of a round child instead of its square corner.

<ComponentPreview name="badge-avatar" />

### Screen reader label

Screen readers hear "12 new" by default. Pass `label` when the context needs more: `{count}` is
replaced by the number as shown, including `99+`. Use your own plural rules when you write it. To
change the default wording for every badge, set the [labels](#labels) once on `DSProvider`.

## API

### Badge

| Prop        | Type                                                                    | Default                            |
| ----------- | ----------------------------------------------------------------------- | ---------------------------------- |
| `count`     | `number`                                                                |                                    |
| `max`       | `number`                                                                | `99`                               |
| `showZero`  | `boolean`                                                               | `false`                            |
| `variant`   | `'solid' \| 'soft'`                                                     | `'solid'`                          |
| `tone`      | `'error' \| 'primary' \| 'neutral' \| 'success' \| 'warning' \| 'info'` | `'error'`                          |
| `size`      | `'sm' \| 'md'`                                                          | `'md'` inline, `'sm'` in an anchor |
| `label`     | `string`, may contain `{count}`                                         | the `count` or `dot` text          |
| `labels`    | `Partial<BadgeLabels>`                                                  |                                    |
| `children`  | `ReactNode`                                                             |                                    |
| `className` | `string`                                                                |                                    |

Every other `span` attribute, including `ref`, is passed through.

### BadgeAnchor

| Prop       | Type                          | Default         |
| ---------- | ----------------------------- | --------------- |
| `badge`    | `ReactNode`                   |                 |
| `overlap`  | `'rectangular' \| 'circular'` | `'rectangular'` |
| `children` | `ReactNode`                   |                 |

Every other `span` attribute, including `ref`, is passed through.

### Data attributes

Badge: `data-slot="badge"`, `data-variant`, `data-tone`, `data-size`, and `data-dot` when it has no
count or text. Part: `data-slot="badge-label"`. BadgeAnchor: `data-slot="badge-anchor"`,
`data-overlap`.

### Labels

Text the badge writes on its own. Pass `labels` to one badge, or set them for every badge with
`<DSProvider labels={{ badge: { … } }}>`. A template can also be a function of its values, so an
i18n library can pick the plural form.

| Key        | Default       | Used for                                                          |
| ---------- | ------------- | ----------------------------------------------------------------- |
| `count`    | `{count} new` | what screen readers hear for a count; `{count}` is the shown text |
| `dot`      | `New`         | what screen readers hear for a dot                                |
| `overflow` | `{max}+`      | the visible text of a count above `max`                           |

`label` on one badge wins over `count` and `dot`. Digits are formatted with `Intl.NumberFormat` for
the current locale before they reach a template.

## Accessibility

- The visible number is hidden from screen readers and replaced by a full label, so "3" is read
  as "3 new", and the dot is read as "New".
- Inside a link or button with a visible label, the badge label joins the accessible name. Put the
  label before the badge in the DOM so it reads "Inbox 3 new"; in a vertical navigation item,
  `flex-col-reverse` keeps the icon on top.
- An icon-only `IconButton` is named by its `aria-label`, which hides the badge text. Include the
  count in that label, for example "Notifications, 3 new".
- A badge does not announce changes. Use a toast or a polite live region when a new count needs to
  be spoken.
- An anchored badge pops in with a short spring when it mounts, and appears instantly under
  reduced motion. Inline badges never animate, so long lists stay calm.
- Contrast is checked with axe for every tone and variant in light, dark and RTL by
  `badge.test.tsx`.
