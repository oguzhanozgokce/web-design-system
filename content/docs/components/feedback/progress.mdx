## Usage

```tsx
import { CircularProgress, LinearProgress } from '@/components/ds/progress';

<LinearProgress label="Uploading photos.zip" value={uploaded} showValueLabel />;

<CircularProgress aria-label="Loading messages" isIndeterminate />;
```

The indeterminate keyframes ship inside the component as a React 19 hoisted `<style>`, so there is
nothing to add to your CSS beyond the theme. A Content Security Policy that blocks inline styles
blocks them too; allow `'unsafe-inline'` in `style-src` on pages that show indeterminate progress.

## Examples

### Indeterminate

Use `isIndeterminate` when you cannot tell how long the work will take. The linear indicator slides
a bar of two fifths of the track from the start edge to the end edge every 1.5 seconds; the
circular one grows and shrinks an arc over its track while it turns. Switch to a determinate value
as soon as you know the size of the job.

<ComponentPreview name="progress-indeterminate" />

### Sizes

The track is a rounded pill in a translucent grey: `sm` is 4px, `md` 8px (the default) and `lg`
12px. Use `sm` inside table rows and cards, `md` for forms and uploads, and `lg` to give a goal or
quota more weight on a dashboard.

<ComponentPreview name="progress-sizes" />

### Tones

`primary` is for ordinary progress and `neutral` draws the fill in the text colour for a quieter
bar. `success`, `warning`, `error` and `info` carry a status, such as a quota that is nearly used
up. Every fill keeps its saturated colour in dark mode. Do not rely on colour alone: say the same
thing in the label or nearby text.

<ComponentPreview name="progress-tones" />

### Value label

`showValueLabel` prints the value at the end of the header, in the muted text colour. It is
formatted with `formatOptions` in the viewer's locale, as a percentage by default. Pass `minValue`
and `maxValue` with a unit format to show the real quantity, or `valueLabel` for text that a number
format cannot express. Screen readers hear the same text.

<ComponentPreview name="progress-value-label" />

### Steps

Use `maxValue` for a count of steps. Every change of `value` widens the fill over 300 ms, so the
bar grows smoothly as the person moves through a flow.

<ComponentPreview name="progress-steps" />

### Circular sizes

`CircularProgress` comes in `sm` (20px), `md` (28px, the default), `lg` (36px) and `xl` (48px). Use
`sm` and `md` inside buttons, list rows and table cells, `lg` and `xl` for a panel that is loading.

<ComponentPreview name="progress-circular" />

### Circular value label

`showValueLabel` puts the formatted value in the middle of the ring. It fits `xl`, and `lg` for
short values. Name the indicator with `aria-labelledby` when a visible title sits next to it.

<ComponentPreview name="progress-circular-value" />

| ----------------- | ----------------------------------------------------------------------- | ---------------------- |
| `value`           | `number`                                                                | `0`                    |
| `minValue`        | `number`                                                                | `0`                    |
| `maxValue`        | `number`                                                                | `100`                  |
| `isIndeterminate` | `boolean`                                                               | `false`                |
| `label`           | `ReactNode`                                                             |                        |
| `showValueLabel`  | `boolean`                                                               | `false`                |
| `formatOptions`   | `Intl.NumberFormatOptions`                                              | `{ style: 'percent' }` |
| `valueLabel`      | `string`                                                                |                        |

through, such as `aria-label`, `aria-labelledby` and `id`.

### Styles

`linearProgressStyles` exposes the slots `root`, `header`, `label`, `value`, `track` and
`indicator`, with the variants `tone`, `size`, `mode` and `motion`. `circularProgressStyles`
exposes `root`, `svg`, `track`, `indicator` and `value`, with `size` and `tone`. The track is
`bg-neutral-soft` and the fill is the tone's solid role, such as `bg-primary-solid`.

### Data attributes

`LinearProgress`: `data-slot="linear-progress"`, `data-tone`, `data-size`, `data-indeterminate`.
Parts: `data-slot="header"`, `"label"`, `"value"`, `"track"`, `"indicator"`.

`CircularProgress`: `data-slot="circular-progress"`, `data-tone`, `data-size`,
`data-indeterminate`. Parts: `data-slot="track"`, `"indicator"`, `"value"`.

### Labels

Fallback names for an indicator without `label`, `aria-label` or `aria-labelledby`. Pass `labels`
to one indicator, or set them for every one with `<DSProvider labels={{ progress: { … } }}>`.

| Key        | Default    | Used for                               |
| ---------- | ---------- | -------------------------------------- |
| `loading`  | `Loading`  | the name of an indeterminate indicator |
| `progress` | `Progress` | the name of a determinate indicator    |

## Accessibility

- Built on React Aria `ProgressBar`: `role="progressbar"` with `aria-valuenow`, `aria-valuemin`,
  `aria-valuemax` and an `aria-valuetext` formatted for the locale. Indeterminate indicators leave
  out the value, which is how screen readers know the length is unknown.
- `label` becomes the accessible name. Without `label`, `aria-label` or `aria-labelledby` the
  indicator falls back to the `loading` or `progress` label, but a specific name such as
  "Uploading photos.zip" is always better.
- A progress bar is not a live region. When a long task finishes, move focus or announce the result
  with a toast or a status message.
- The bar mirrors in right-to-left languages; the circle keeps turning clockwise.
- With reduced motion, from the operating system or `DSProvider motion="reduced"`, value changes
  jump instead of growing and indeterminate indicators become a full-width slow pulse.
  `motion="disabled"` stops the pulse too and leaves a half-strength bar.
- Contrast and structure are checked with axe in light, dark and RTL by `progress.test.tsx`.
