## Examples

### Sizes

`sm` fits a dashboard card, a side panel or a list: a 40px icon well, a 14px title, 12px text and
small soft and ghost actions. `md`, the default, suits a table or a section: a 48px well, an 18px
title, a description of at most 360px and a solid primary action. `lg` fills most of the viewport
for a screen with nothing on it yet, with a 64px well and a 24px title. The icon always sits in a
neutral grey circle in the muted text colour, so the accent stays on the action.

### Page with an illustration

`illustration` replaces the icon circle and is sized to the empty state. Draw it with role
colours (`fill-neutral-soft`, `fill-surface-raised`, `fill-primary-solid`) so it follows the theme
and dark mode.

### Inside a table

Put a `sm` empty state in a single cell that spans every column, so the table keeps its
header and caption. Say why it is empty and offer the way out, such as clearing a filter.

## Writing empty states

- Say what will be here and how to get it: "No files yet", then "Upload your first file".
- Give one primary action. A second action is for an alternative route, such as creating a folder.
- Do not invent numbers, reviews or people to fill the space.

## API

### EmptyState

| Prop              | Type                          | Default  |
| ----------------- | ----------------------------- | -------- |
| `title`           | `ReactNode`                   | required |
| `description`     | `ReactNode`                   |          |
| `children`        | `ReactNode`                   |          |
| `icon`            | `ReactNode`                   |          |
| `illustration`    | `ReactNode`; wins over `icon` |          |
| `primaryAction`   | `ReactNode`                   |          |
| `secondaryAction` | `ReactNode`                   |          |
| `size`            | `'sm' \| 'md' \| 'lg'`        | `'md'`   |
| `headingLevel`    | `1 \| 2 \| 3 \| 4 \| 5 \| 6`  | `2`      |

Every other `div` prop goes to the root. `emptyStateStyles` is exported for custom compositions.

Buttons in `primaryAction` and `secondaryAction` pick up a variant and size from the empty state
unless you set them:

| Size | Primary                  | Secondary                |
| ---- | ------------------------ | ------------------------ |
| `sm` | `soft`, `neutral`, `sm`  | `ghost`, `neutral`, `sm` |
| `md` | `solid`, `primary`, `md` | `soft`, `neutral`, `md`  |
| `lg` | `solid`, `primary`, `md` | `soft`, `neutral`, `md`  |

### Data attributes

`data-size`. Parts: `data-slot="empty-state"`, `"media"`, `"content"`, `"title"`,
`"description"`, `"extra"`, `"actions"`.

## Accessibility

- The title is a real heading. Set `headingLevel` so it fits the page outline: usually one level
  below the heading of the section that holds it.
- The icon or illustration is decorative and hidden from assistive technology. Put anything
  meaningful in the title or description.
- An empty state is not a live region by itself. When it replaces content after a fetch or a
  search, render it through `ContentState`, which announces it.
- Contrast is checked with axe in light, dark and RTL by `empty-state.test.tsx`.
