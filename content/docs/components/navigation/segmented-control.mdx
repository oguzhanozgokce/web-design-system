## Usage

```tsx
import { SegmentedControl, SegmentedControlItem } from '@/components/ds/segmented-control';

<SegmentedControl aria-label="Calendar view" defaultSelectedKeys={['week']}>
  <SegmentedControlItem id="day">Day</SegmentedControlItem>
  <SegmentedControlItem id="week">Week</SegmentedControlItem>
  <SegmentedControlItem id="month">Month</SegmentedControlItem>
</SegmentedControl>;
```

Use a segmented control to switch a view or a setting between two to five short options. To move
between sections of content, use [Tabs](/docs/components/navigation/tabs).

The options sit on a neutral tinted track. The selected one is a raised pill on the segment
surface, white in light mode and a lifted grey in dark mode, with a small shadow. Unselected labels
are grey and darken on hover; the accent colour is not used.

## Examples

### Sliding selection

In single selection mode the raised pill slides to the selected segment over 250ms on the fluid
curve. It is measured from the selected segment, so it fits any label length, translation or
right-to-left layout, and it re-measures when a label, the width or the page direction changes.
Under reduced motion it moves without animation.

<ComponentPreview name="segmented-control-sliding" />

### Multiple selection

`selectionMode="multiple"` lets people turn several options on. Each selected segment gets its own
raised pill and a check, so the state reads without relying on the fill alone. The check slides in
on its own when the segment has no icon. Multiple selection may be empty, so say what an empty
selection means. A visible label linked with `aria-labelledby` names the control for everyone.

<ComponentPreview name="segmented-control-multiple" />

### Sizes

`md` (40px) is the default. `sm` (32px) fits card headers, toolbars and dense tables, and `lg`
(48px) suits a page-level switch. The segments are 8px shorter than the track.

<ComponentPreview name="segmented-control-sizes" />

### Icons

`icon` goes before the label. An icon-only segment needs an `aria-label`. With `showCheckmark`, the
check replaces the icon of a selected segment.

<ComponentPreview name="segmented-control-icons" />

### Full width

`fullWidth` stretches the control and shares the width equally, so the segments line up with the
fields around them in a form or a narrow card. Long labels are truncated.

<ComponentPreview name="segmented-control-full-width" />

### Disabled

`isDisabled` on the control disables every segment; `isDisabled` on a `SegmentedControlItem`
disables one. Disabled segments are drawn at half opacity with a not-allowed cursor. Say nearby why
an option is unavailable.

<ComponentPreview name="segmented-control-disabled" />

### Controlled

`selectedKeys` and `onSelectionChange` control the selection. The callback always receives a `Set`,
in single selection mode too.

<ComponentPreview name="segmented-control-controlled" />

## API

### SegmentedControl

| Prop                     | Type                       | Default                                         |
| ------------------------ | -------------------------- | ----------------------------------------------- |
| `size`                   | `'sm' \| 'md' \| 'lg'`     | `'md'`                                          |
| `fullWidth`              | `boolean`                  | `false`                                         |
| `selectionMode`          | `'single' \| 'multiple'`   | `'single'`                                      |
| `selectedKeys`           | `Iterable<Key>`            |                                                 |
| `defaultSelectedKeys`    | `Iterable<Key>`            |                                                 |
| `onSelectionChange`      | `(keys: Set<Key>) => void` |                                                 |
| `disallowEmptySelection` | `boolean`                  | `true` in single mode, `false` in multiple mode |
| `showCheckmark`          | `boolean`                  | `true` in multiple mode, else `false`           |
| `isDisabled`             | `boolean`                  | `false`                                         |
| `aria-label`             | `string`                   |                                                 |

Every other [React Aria ToggleButtonGroup](https://react-aria.adobe.com/ToggleButtonGroup) prop is
passed through. The pill slides in single selection mode; with `selectionMode="multiple"` each
selected segment is filled instead.

### SegmentedControlItem

| Prop         | Type        | Default |
| ------------ | ----------- | ------- |
| `id`         | `Key`       |         |
| `icon`       | `ReactNode` |         |
| `isDisabled` | `boolean`   | `false` |
| `aria-label` | `string`    |         |

Every other [React Aria ToggleButton](https://react-aria.adobe.com/ToggleButton) prop is passed
through. A segment without a text label must have an `aria-label` or `aria-labelledby`; the types
require one.

### Data attributes

SegmentedControl: `data-slot="segmented-control"`, `data-size`, `data-selection-mode`,
`data-full-width`, `data-disabled`, `data-thumb-ready` (once the sliding pill has been measured). SegmentedControlItem: `data-slot="segment"`,
`data-selected`, `data-hovered`, `data-pressed`, `data-focus-visible`, `data-disabled`. Parts:
`data-slot="thumb"` (with `data-visible`), `"icon"`, `"check"`, `"label"`.

Until the pill is measured, for example before hydration, the selected segment paints its own fill,
so the control never renders without a visible selection.

## Accessibility

- In single selection mode the control is a `radiogroup` of `radio` items with `aria-checked`. In
  multiple selection mode it is a `toolbar` of buttons with `aria-pressed`.
- The control is one tab stop. Arrow keys move between segments, mirrored in right-to-left
  languages, and Space or Enter selects the focused one.
- The sliding pill and the check are decorative and hidden from assistive technology; the selected
  state is announced by the role.
- The focus ring is a 2px outline drawn inside the focused segment, so it is not clipped by the
  track.
- Give each control an `aria-label`, or point `aria-labelledby` at a visible heading.
