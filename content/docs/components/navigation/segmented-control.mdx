## Usage

```tsx
import { SegmentedControl, SegmentedControlItem } from '@/components/ds/segmented-control';

<SegmentedControl aria-label="Report period" defaultSelectedKeys={['week']}>
  <SegmentedControlItem id="day">Day</SegmentedControlItem>
  <SegmentedControlItem id="week">Week</SegmentedControlItem>
  <SegmentedControlItem id="month">Month</SegmentedControlItem>
</SegmentedControl>;
```

Use a segmented control to switch a view or a setting between two to five short options. To move
between sections of content, use [Tabs](/docs/components/navigation/tabs).

## Examples

### Thumb

`variant="thumb"` puts the options on a tinted track and slides a filled thumb under the selected
one on the spatial spring. The thumb is measured from the selected segment, so it fits any label
length, translation or right-to-left layout, and it re-measures when a label, the width or the
page direction changes.
It suits the period switch in a dashboard card. Under reduced motion it moves without animation.

<ComponentPreview name="segmented-control-thumb" />

### Multiple selection

`selectionMode="multiple"` lets people turn several options on. Selected segments show a check, so
the state reads without colour. The check slides in on its own when the segment has no icon.
Multiple selection may be empty, so say what an empty selection means. A visible label linked with
`aria-labelledby` names the control for everyone.

<ComponentPreview name="segmented-control-multiple" />

### Sizes

`md` (40px) is the default. `sm` (32px) fits card headers, toolbars and dense tables.

<ComponentPreview name="segmented-control-sizes" />

### Icons

`icon` goes before the label. An icon-only segment needs an `aria-label`. With `showCheckmark`, the
check replaces the icon of a selected segment, as Material 3 does.

<ComponentPreview name="segmented-control-icons" />

### Full width

`fullWidth` stretches the control and shares the width equally, so the segments line up with the
fields around them in a form or a narrow card. Long labels are truncated.

<ComponentPreview name="segmented-control-full-width" />

### Disabled

`isDisabled` on the control disables every segment; `isDisabled` on a `SegmentedControlItem`
disables one. Say nearby why an option is unavailable.

<ComponentPreview name="segmented-control-disabled" />

### Controlled

`selectedKeys` and `onSelectionChange` control the selection. The callback always receives a `Set`,
in single selection mode too.

## API

### SegmentedControl

| Prop                     | Type                       | Default                                            |
| ------------------------ | -------------------------- | -------------------------------------------------- |
| `variant`                | `'outlined' \| 'thumb'`    | `'outlined'`                                       |
| `size`                   | `'sm' \| 'md'`             | `'md'`                                             |
| `fullWidth`              | `boolean`                  | `false`                                            |
| `selectionMode`          | `'single' \| 'multiple'`   | `'single'`                                         |
| `selectedKeys`           | `Iterable<Key>`            |                                                    |
| `defaultSelectedKeys`    | `Iterable<Key>`            |                                                    |
| `onSelectionChange`      | `(keys: Set<Key>) => void` |                                                    |
| `disallowEmptySelection` | `boolean`                  | `true` in single mode, `false` in multiple mode    |
| `showCheckmark`          | `boolean`                  | `true` for outlined multiple selection, else false |
| `isDisabled`             | `boolean`                  | `false`                                            |
| `aria-label`             | `string`                   |                                                    |

Every other [React Aria ToggleButtonGroup](https://react-aria.adobe.com/ToggleButtonGroup) prop is
passed through. The thumb slides in single selection mode; with `selectionMode="multiple"` the thumb
style fills each selected segment instead.

### SegmentedControlItem

| Prop         | Type        | Default |
| ------------ | ----------- | ------- |
| `id`         | `Key`       |         |
| `icon`       | `ReactNode` |         |
| `isDisabled` | `boolean`   | `false` |
| `aria-label` | `string`    |         |

Every other [React Aria ToggleButton](https://react-aria.adobe.com/ToggleButton) prop is passed
through. A segment without a text label must have an `aria-label` or `aria-labelledby`; the types
require one.

### Data attributes

SegmentedControl: `data-slot="segmented-control"`, `data-variant`, `data-size`,
`data-selection-mode`, `data-full-width`, `data-disabled`, `data-thumb-ready` (once the thumb has
been measured). SegmentedControlItem: `data-slot="segment"`,
`data-selected`, `data-hovered`, `data-pressed`, `data-focus-visible`, `data-disabled`. Parts:
`data-slot="thumb"` (with `data-visible`), `"icon"`, `"check"`, `"label"`.

Until the thumb is measured, for example before hydration, the selected segment paints its own fill,
so the control never renders without a visible selection.

## Accessibility

- In single selection mode the control is a `radiogroup` of `radio` items with `aria-checked`. In
  multiple selection mode it is a `toolbar` of buttons with `aria-pressed`.
- The control is one tab stop. Arrow keys move between segments, mirrored in right-to-left
  languages, and Space or Enter selects the focused one.
- The thumb and the check are decorative and hidden from assistive technology; the selected state
  is announced by the role.
- Give each control an `aria-label`, or point `aria-labelledby` at a visible heading.
- Contrast is checked with axe in light, dark and RTL by `segmented-control.test.tsx`.
