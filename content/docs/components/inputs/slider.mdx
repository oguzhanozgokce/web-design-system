## Usage

```tsx
import { Slider } from '@/components/ds/slider';

<Slider label="Volume" defaultValue={40} />;
```

Use a slider when the rough position matters more than the exact number: volume, brightness,
limits and ranges. When people know the exact number they want, a number field is faster.

The slider is a 4px rail with a round thumb. The filled part uses the solid primary, the rest an
opaque grey, and the thumb sits on the light thumb surface with a small shadow.

## Examples

### Range

Pass an array to `defaultValue` or `value` to get one thumb per entry. The header shows the range
formatted for the locale, and each thumb is announced as Minimum or Maximum. Name the thumbs of one
slider with `thumbLabels`, or change the defaults with `labels`.

<ComponentPreview name="slider-range" />

### Sizes

`md` is the default: a 20px thumb on a 4px rail. `sm` has a 16px thumb for dense forms and
toolbars, and `lg` a 24px thumb on a 6px rail for settings screens where the slider is the main
control.

<ComponentPreview name="slider-sizes" />

### Stops

When `step` divides the range into 20 or fewer intervals and there are no `marks`, the rail shows a
small dot at each position so people can see where the thumb will land. With `marks`, the dots sit
at the marks instead. `showStops` turns the step stops on or off explicitly. A continuous slider
shows no dots.

<ComponentPreview name="slider-stops" />

### Marks

`marks` adds labelled positions under the track. A plain number is formatted like the value, so
`[0, 15, 30, 45, 60]` with a `minute` unit reads "15 min" in English and "15 Min." in German.
Pass `{ value, label }` for words instead of numbers.

<ComponentPreview name="slider-marks" />

### Centred

`fillOffset` sets the value the fill grows from. Set it to `0` on a range that crosses zero for
adjustments that can go either way, such as exposure or audio balance. A dot on the rail marks the
offset.

<ComponentPreview name="slider-centered" />

### Vertical

`orientation="vertical"` centres the label and value above the track in a column 240px tall.
Change the height with `className`. Up and Page Up increase the value.

<ComponentPreview name="slider-vertical" />

### Controlled

Use `value` and `onChange` when something else on the page reacts to the value as it moves. Use
`onChangeEnd` to save only when the thumb is released.

<ComponentPreview name="slider-controlled" />

### Disabled

Disabled sliders keep showing their value, so people can still read the setting.

## API

### Slider

| Prop                 | Type                                  | Default          |
| -------------------- | ------------------------------------- | ---------------- |
| `label`              | `ReactNode`                           |                  |
| `description`        | `ReactNode`                           |                  |
| `size`               | `'sm' \| 'md' \| 'lg'`                | `'md'`           |
| `orientation`        | `'horizontal' \| 'vertical'`          | `'horizontal'`   |
| `value`              | `number \| number[]`                  |                  |
| `defaultValue`       | `number \| number[]`                  | `minValue`       |
| `onChange`           | `(value: number \| number[]) => void` |                  |
| `onChangeEnd`        | `(value: number \| number[]) => void` |                  |
| `minValue`           | `number`                              | `0`              |
| `maxValue`           | `number`                              | `100`            |
| `step`               | `number`                              | `1`              |
| `formatOptions`      | `Intl.NumberFormatOptions`            |                  |
| `marks`              | `ReadonlyArray<number \| SliderMark>` |                  |
| `showStops`          | `boolean`                             | automatic        |
| `fillOffset`         | `number`                              | `minValue`       |
| `showValueLabel`     | `boolean`                             | `true`           |
| `showValueIndicator` | `boolean`                             | `true`           |
| `thumbLabels`        | `ReadonlyArray<string \| undefined>`  | Minimum, Maximum |
| `labels`             | `Partial<SliderLabels>`               |                  |
| `name`               | `string`                              |                  |
| `form`               | `string`                              |                  |
| `isDisabled`         | `boolean`                             | `false`          |

`SliderMark` is `{ value: number; label?: ReactNode }`. A mark without a label draws a stop and no
text. `fillOffset` applies to single-value sliders; a range always fills between its thumbs. `name`
and `form` are set on every thumb's input, so a range submits one entry per thumb. Without a
visible `label`, pass `aria-label`. Every other [React Aria Slider](https://react-aria.adobe.com/Slider)
prop except `render` is passed through.

### Data attributes

Root (`data-slot="slider"`): `data-size`, `data-orientation`, `data-disabled`. Thumbs
(`data-slot="thumb"`): `data-dragging`, `data-focused`, `data-focus-visible`, `data-hovered`,
`data-disabled`. Rail segments and stops (`data-slot="segment"`, `"stop"`): `data-tone` is
`active` or `inactive`. Other parts: `"header"`, `"label"`, `"output"`, `"control"`, `"track"`
(the pointer area around the rail), `"rail"`, `"stops"`, `"value-indicator"`, `"bubble"`,
`"marks"`, `"mark"`, `"description"`.

### Labels

Text the slider writes on its own. Pass `labels` to one slider, or set them for every slider with
`<DSProvider labels={{ slider: { … } }}>`. `thumbLabels` wins over both for the thumbs it names.

| Key       | Default   | Used for                                                       |
| --------- | --------- | -------------------------------------------------------------- |
| `minimum` | `Minimum` | the accessible name of a range's first thumb, before the label |
| `maximum` | `Maximum` | the accessible name of a range's last thumb, before the label  |

## Accessibility

- Built on React Aria `Slider`: each thumb is a native range input, so arrow keys, Page Up, Page
  Down, Home and End work, and screen readers hear the formatted value through `aria-valuetext`.
- The label names the group and every thumb; a range adds Minimum and Maximum so the two thumbs
  can be told apart. The description is linked with `aria-describedby`.
- The slider takes its direction from the `DSProvider` locale, the same source React Aria uses for
  arrow keys, and sets `dir` on its root, so in Arabic the track fills from the right and Right
  Arrow lowers the value.
- The value bubble appears while dragging and on keyboard focus, never on hover, and is hidden from
  screen readers because the value is already announced. Near either end it shifts along the rail
  so it never reaches past the slider's own edges, which keeps it inside the viewport on a phone.
  With the system's reduced motion setting or `DSProvider motion="reduced"` it fades without
  scaling and the thumb no longer shrinks while dragged. With `motion="disabled"` it appears
  instantly.
- The focus ring is a 2px outline around the thumb. A disabled slider is drawn at half opacity
  with a not-allowed cursor.
- A disabled slider marks its group `aria-disabled`, so assistive technology reports the whole
  control as unavailable.
- In forced colours mode (Windows High Contrast) the fill uses `Highlight`, the rest of the rail
  gets an outline, and the thumb and stops switch to system colours, so the slider stays visible.
  A disabled slider uses `GrayText`.
- Contrast is checked with axe in light, dark and RTL by `slider.test.tsx`.
