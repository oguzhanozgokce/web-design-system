## Usage

```tsx
import { ListBoxItem } from '@/components/ds/list-box';
import { Select } from '@/components/ds/select';

<Select label="Country" items={countries} defaultValue="JP">
  {(country) => <ListBoxItem description={country.id}>{country.name}</ListBoxItem>}
</Select>;
```

The trigger looks like a [Text field](/docs/components/inputs/text-field): label, description,
errors, sizes, variants and the required indicator follow the
[Field](/docs/components/inputs/field) contract. Options are
[List box](/docs/components/inputs/list-box) items, shown on a raised overlay panel (16 px radius,
hairline border, medium shadow) at least as wide as the trigger. Rows are 36 px with 12 px corners;
the selected one carries a check mark. On a narrow screen the popover never grows past the viewport, so the page does not scroll
sideways and close it.

Use a select for a short, known list. When people need to search, or the list has more than about
fifteen options, use a [Combo box](/docs/components/inputs/combo-box).

## Examples

### Variants

`outline` is the default and suits most forms. `soft` is a borderless neutral tint for toolbars and
filter rows, and matches soft text fields in the same form. While the list is open, the trigger keeps
the focused frame and the chevron turns.

<ComponentPreview name="select-variants" />

### Sizes

`md` (40 px) is the default. `sm` (32 px) suits toolbars and table footers and also tightens the
list rows to 32 px. `lg` (48 px) suits touch-first and marketing forms.

<ComponentPreview name="select-sizes" />

### Icons

An item's `startIcon` also shows in the trigger once that item is selected. `startAdornment` puts a
fixed icon at the start of the trigger, for a control whose label is hidden or whose purpose is a
verb such as sort or filter.

<ComponentPreview name="select-icons" />

### Avatars

Item `avatar`s show in the list and, smaller, in the trigger. Descriptions only appear in the list,
so the trigger stays one line.

<ComponentPreview name="select-avatars" />

### Sections

Group options with `ListBoxSection`. Section titles are announced with the group but are not
selectable.

<ComponentPreview name="select-sections" />

### Multiple selection

`selectionMode="multiple"` keeps the list open while people pick, and `value` becomes an array of
keys. `valueDisplay` sets how the trigger shows the choice: `text` (the default) lists the labels in
the locale's list format, `count` shows “3 selected”, and `chips` shows the first `maxChips` labels
(2 by default) as small neutral pills and a “+n” chip. Screen readers always hear the full list.

<ComponentPreview name="select-multiple" />

### Validation

`isRequired` blocks native form submission until something is chosen, and the error replaces the
description. Pass `name` so the value is submitted with the form, and `validationBehavior="aria"` to
validate as people go instead of on submit.

<ComponentPreview name="select-validation" />

### Disabled

`isDisabled` locks the whole control and fades it to half opacity. `disabledKeys` or an item's `isDisabled` keeps one option
visible but out of reach; explain why in the description.

<ComponentPreview name="select-disabled" />

### Async options

`isLoading` swaps the chevron for a spinner, and the open list shows a “Loading…” row. Add
`onLoadMore` to fetch the next page when the end of the list scrolls into view. An empty list shows
“No options” unless you pass `renderEmptyState`.

<ComponentPreview name="select-async" />

### Controlled

Pass `value` and `onChange` to own the selection. `onChange` receives the key, or an array of keys in
multiple mode.

<ComponentPreview name="select-controlled" />

## API

### Select

| Prop                    | Type                                                | Default            |
| ----------------------- | --------------------------------------------------- | ------------------ |
| `items`                 | `Iterable<T>`                                       |                    |
| `children`              | `ReactNode \| ((item: T) => ReactNode)`             |                    |
| `dependencies`          | `ReadonlyArray<unknown>`                            |                    |
| `selectionMode`         | `'single' \| 'multiple'`                            | `'single'`         |
| `value`                 | `Key \| null`, or `Key[]` when multiple             |                    |
| `defaultValue`          | `Key \| null`, or `Key[]` when multiple             |                    |
| `onChange`              | `(value: Key \| null) => void`, or `(value: Key[])` |                    |
| `placeholder`           | `string`                                            | “Select an option” |
| `startAdornment`        | `ReactNode`                                         |                    |
| `valueDisplay`          | `'text' \| 'count' \| 'chips'`                      | `'text'`           |
| `maxChips`              | `number`                                            | `2`                |
| `isLoading`             | `boolean`                                           | `false`            |
| `onLoadMore`            | `() => void`                                        |                    |
| `renderEmptyState`      | `(renderProps: ListBoxRenderProps) => ReactNode`    | “No options”       |
| `disabledKeys`          | `Iterable<Key>`                                     |                    |
| `allowsEmptyCollection` | `boolean`                                           | `true`             |
| `isOpen`                | `boolean`                                           |                    |
| `onOpenChange`          | `(isOpen: boolean) => void`                         |                    |
| `labels`                | `Partial<SelectLabels & FieldLabels>`               |                    |

Plus the [shared Field props](/docs/components/inputs/field#shared-props) and every other
[React Aria Select](https://react-aria.adobe.com/Select) prop, such as `name`, `autoComplete`,
`validate` and `shouldCloseOnSelect`. `className` styles the root. `isReadOnly` is not supported by
React Aria's Select; use `isDisabled` or show the value as text.

### selectStyles

`selectStyles({ variant, animated })` returns class functions for `trigger`, `value`, `chips`,
`chip`, `more`, `indicator`, `arrow`, `popover` and `list`. `variant` is `'outline'` or `'soft'` and
draws the open state of the trigger. `animated` (default `true`) turns the chevron over 150 ms;
Select sets it to `false` when `DSProvider` motion is reduced or off.
The trigger also takes the `container` classes from
[`fieldStyles`](/docs/components/inputs/field#fieldstyles).

### Data attributes

The root has `data-slot="select"`, `data-size`, `data-variant` (`outline` or `soft`), `data-loading`, `data-open`,
`data-focused`, `data-focus-visible`, `data-invalid`, `data-disabled` and `data-required`. Parts:
`data-slot="trigger"` (with `data-pressed` while open and `data-invalid`), `"value"` (with
`data-placeholder`), `"count"`, `"chips"`, `"chip"`, `"more"`, `"indicator"` and `"popover"`. The list parts are
listed on [List box](/docs/components/inputs/list-box#data-attributes).

### Labels

Text the select writes on its own. Pass `labels` to one select, or set them for every select with
`<DSProvider labels={{ select: { … } }}>`. A `placeholder` prop wins over `labels.placeholder`.
`labels` also takes the [Field](/docs/components/inputs/field) keys, such as `optional` for the
label's “(optional)” marker, which `DSProvider` sets under `field`.

| Key             | Default            | Used for                                          |
| --------------- | ------------------ | ------------------------------------------------- |
| `placeholder`   | `Select an option` | the trigger while nothing is selected             |
| `empty`         | `No options`       | the open list when it has no options              |
| `loading`       | `Loading…`         | the row at the end of the open list while loading |
| `selectedCount` | `{count} selected` | the trigger with `valueDisplay="count"`           |
| `moreCount`     | `+{count}`         | the chip for selected options past `maxChips`     |

`{count}` arrives formatted with the locale's number format. A template can also be a function of
it, for languages with plural forms: `selectedCount: ({ count }) => …`.

## Accessibility

- Built on React Aria `Select`: Enter, Space and the arrow keys open the list, typing jumps to a
  matching option even while closed, and Escape closes it and returns focus to the trigger.
- The trigger is named by the label and the current value. With chips, a hidden copy of the full
  value is read instead of the truncated chips; with a count, the selected labels follow the count.
- The popover takes its direction from the locale, so the list mirrors in right-to-left languages
  even when only part of the page is right-to-left.
- A hidden native `select` keeps autofill and form submission working.
