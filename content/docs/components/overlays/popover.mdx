## Usage

```tsx
import { Button } from '@/components/ds/button';
import { Popover, PopoverDialog, PopoverTrigger } from '@/components/ds/popover';

<PopoverTrigger>
  <Button>Next meeting</Button>
  <Popover>
    <PopoverDialog title="Weekly sync" showCloseButton>
      Mondays at 10:00, by video call.
    </PopoverDialog>
  </Popover>
</PopoverTrigger>;
```

`PopoverTrigger` takes two children: the element that opens the popover and the `Popover`. Put a
`PopoverDialog` inside for content that people read or fill in. Select, ComboBox and Menu reuse the
same `Popover` surface with a list inside instead.

## Examples

### Morph popover

`animation="morph"` unfolds the surface from the trigger while its content fades into place at
its natural size. Opening takes 250ms; closing takes 150ms. The default `scale` animation stays
unchanged. The switches below update the workspace preferences; Reset restores their defaults.

<ComponentPreview name="popover-morph" />

### Hover preview

`PopoverPreviewTrigger` opens a non-modal preview on hover, keyboard focus or a touch long press.
People can move the pointer into the panel without crossing a closing gap. Keyboard focus stays
on the trigger until Tab moves it into the preview; Escape closes it and returns focus.
This example also opens on a regular tap through the button's `onPress` and lets you save the collection.

<ComponentPreview name="popover-morph-preview" />

```tsx
import { Button } from '@/components/ds/button';
import { Popover, PopoverPreviewTrigger } from '@/components/ds/popover';

<PopoverPreviewTrigger>
  <Button>Collection preview</Button>
  <Popover animation="morph" aria-label="Collection preview" className="w-72 p-4">
    <p className="mb-3">Four quiet scenes for a fresh perspective.</p>
    <Button onPress={saveCollection}>Save collection</Button>
  </Popover>
</PopoverPreviewTrigger>;
```

Use ordinary content and an accessible name on the preview `Popover`. `PopoverDialog` moves
focus on mount, so reserve it for press-opened dialogs. Put forms behind a press trigger.

### Placement and arrow

`placement` accepts `top`, `bottom`, `start`, `end` and the combined forms such as `bottom start`.
`start` and `end` follow the reading direction, so they swap sides in Arabic. The popover flips to
the other side when it does not fit. `showArrow` points at the trigger and adds 4px to the default
`offset`.

<ComponentPreview name="popover-placement" />

### With a form

`PopoverDialog` accepts a function as children. It receives `close`, so a form can close the
popover after it saves. Focus moves into the popover when it opens and returns to the trigger when
it closes. Keep popover forms to one or two fields; anything longer belongs in a dialog or a sheet.

<ComponentPreview name="popover-form" />

### Padding

`PopoverDialog` pads its content 16px. `padding="sm"` brings it to 12px for a single line of help
text or a compact list.

### Anchored to another element

Without a `PopoverTrigger`, pass `triggerRef` and control `isOpen` yourself. The popover then
points at any element, such as a chart or a meter, while focus still returns to the button that
opened it.

## API

### PopoverTrigger

React Aria [DialogTrigger](https://react-aria.adobe.com/Dialog). Its first child must be a
pressable component such as `Button`.

| Prop           | Type                        | Default |
| -------------- | --------------------------- | ------- |
| `isOpen`       | `boolean`                   |         |
| `defaultOpen`  | `boolean`                   | `false` |
| `onOpenChange` | `(isOpen: boolean) => void` |         |

### PopoverPreviewTrigger

React Aria [PreviewTrigger](https://react-aria.adobe.com/PreviewTrigger), with a focusable trigger
and a `Popover` as its two children.

| Prop           | Type                        | Default |
| -------------- | --------------------------- | ------- |
| `isOpen`       | `boolean`                   |         |
| `defaultOpen`  | `boolean`                   | `false` |
| `onOpenChange` | `(isOpen: boolean) => void` |         |
| `delay`        | `number`                    | `300`   |
| `closeDelay`   | `number`                    | `200`   |
| `isDisabled`   | `boolean`                   | `false` |

Disabling a preview closes it without disabling the trigger's own action. Controlled state is
supported. React Aria may skip the delay and entrance animation when moving between warm previews.

### Popover

| Prop               | Type                                                       | Default            |
| ------------------ | ---------------------------------------------------------- | ------------------ |
| `placement`        | `'top' \| 'bottom' \| 'start' \| 'end' \| 'bottom start'…` | `'bottom'`         |
| `offset`           | `number`                                                   | `8`, `12` if arrow |
| `crossOffset`      | `number`                                                   | `0`                |
| `showArrow`        | `boolean`                                                  | `false`            |
| `animation`        | `'scale' \| 'morph'`                                       | `'scale'`          |
| `shouldFlip`       | `boolean`                                                  | `true`             |
| `containerPadding` | `number`                                                   | `12`               |
| `isNonModal`       | `boolean`                                                  | `false`            |
| `triggerRef`       | `RefObject<Element>`                                       | from the trigger   |
| `isOpen`           | `boolean`                                                  | from the trigger   |
| `onOpenChange`     | `(isOpen: boolean) => void`                                |                    |

Every other [React Aria Popover](https://react-aria.adobe.com/Popover) prop is passed through.
Buttons inside it keep their own size and variant even when the trigger sits in a [Button
Group](/docs/components/actions/button-group).

### PopoverDialog

| Prop              | Type                                                               | Default |
| ----------------- | ------------------------------------------------------------------ | ------- |
| `title`           | `ReactNode`                                                        |         |
| `showCloseButton` | `boolean`                                                          | `false` |
| `padding`         | `'sm' \| 'md'`                                                     | `'md'`  |
| `labels`          | `Partial<PopoverLabels>`                                           |         |
| `children`        | `ReactNode \| ((renderProps: { close: () => void }) => ReactNode)` |         |
| `aria-label`      | `string`                                                           |         |
| `className`       | `string`                                                           |         |

Without a `title`, the dialog takes its accessible name from the trigger. A standalone popover
without a trigger needs `title` or `aria-label`. The close button is a 28px ghost, neutral
[Icon Button](/docs/components/actions/icon-button).

### PopoverArrow

The arrow `Popover` renders with `showArrow`. Use it in custom overlays; set its colour with a
`text-` role class, for example `<PopoverArrow className="text-inverse-surface" />`.

### Styling

| Part    | Classes                                                                |
| ------- | ---------------------------------------------------------------------- |
| surface | `rounded-overlay bg-surface-overlay text-sm text-on-surface shadow-md` |
| arrow   | `fill-current text-surface-overlay`                                    |
| dialog  | `p-4 gap-2`, `p-3 gap-1.5` with `padding="sm"`                         |
| title   | `text-sm font-semibold text-on-surface`                                |
| body    | `text-sm text-on-surface-variant`                                      |
| close   | a 28px ghost, neutral Icon Button                                      |

`popoverStyles({ motion, animation, className })` returns the surface classes above, the transform origin at
the trigger and the enter and exit animations. Select, ComboBox and Menu build their lists on it.
`usePopoverMotion()` returns `'spatial'`, `'fade'` or `'none'` from the `DSProvider` motion setting
and the system preference, so a custom overlay animates the same way. `popoverDialogStyles({
padding })` exposes the `base`, `header`, `title`, `close` and `body` slots.

With `animation="morph"`, the surface is painted by `::before`; customize it with `before:`
utilities. Content lives in a `data-slot="popover-content"` wrapper that stays mounted when the
motion preference changes. The effect uses transform and opacity, without blur filters, per-frame
React updates or an additional animation dependency.

### Data attributes

Popover: `data-slot="popover"`, `data-placement`, `data-arrow`, `data-entering`, `data-exiting`,
`data-trigger`, `data-animation`. Morph content: `data-slot="popover-content"`.
Dialog: `data-slot="popover-dialog"` with `data-padding`. Parts:
`data-slot="arrow"`, `"header"`, `"title"`, `"body"`. The close button is an Icon Button
(`data-slot="icon-button"`) with `slot="close"`.

### Labels

Text the popover writes on its own. Pass `labels` to one `PopoverDialog`, or set them for every
popover with `<DSProvider labels={{ popover: { … } }}>`.

| Key     | Default | Used for                                                      |
| ------- | ------- | ------------------------------------------------------------- |
| `close` | `Close` | the accessible name of the button that `showCloseButton` adds |

## Accessibility

- Built on React Aria `Popover` and `Dialog`. The trigger gets `aria-expanded` and
  `aria-controls`, and the popover is a dialog named by its title or by the trigger.
- A press-opened dialog moves focus inside, contains it while open, and returns it to the trigger
  on close. Escape and a press outside close it. Hover previews are non-modal and preserve focus
  on the trigger until the user tabs into them.
- Screen reader users get hidden dismiss buttons at both ends of the popover.
- The popover takes its direction and `lang` from the locale, so `start` and `end` placements and
  the arrow are correct in Arabic, and screen readers pick the right voice.
- Both animations use the actual trigger anchor after collision handling. Reduced motion, from
  the system or `DSProvider`, uses a fade instead; `motion="disabled"` opens and closes immediately.
