## Usage

```tsx
import { IconButton } from '@/components/ds/icon-button';

<IconButton aria-label="Edit" icon={<EditIcon />} onPress={edit} />;
```

An action that shows only an icon is always an `IconButton`, never a `Button` with no label.
`aria-label` is required by the types, because the icon says nothing to a screen reader. Pair it
with a [tooltip](/docs/components/overlays/tooltip) when the icon is not obvious.

Inside a [ButtonGroup](/docs/components/actions/button-group) or `ToggleButtonGroup`, icon buttons
take `size`, `tone`, `isDisabled` and the variant from the group, so a toolbar is set up once. A
prop on the icon button still wins.

## Examples

### Variants

The same four variants as [Button](/docs/components/actions/button). `ghost` is the default: no
fill until it is hovered, for toolbars, table rows and headers. `soft` gives a translucent fill,
`outline` a hairline border, and `solid` marks the one main action in a group. The tone defaults to
`neutral`, except for `solid`, which is `primary`.

<ComponentPreview name="icon-button-variants" />

### Sizes

`md` (40px) is the default. `xs` (28px) and `sm` (32px) suit dense toolbars, table rows and close
buttons; on touch screens their hit area grows to 48px without changing the layout. `lg` (48px)
suits media controls. Icons are 16px at `xs` and `sm`, 20px at `md` and 24px at `lg`.

<ComponentPreview name="icon-button-sizes" />

### Dense rows and close buttons

Every icon button is a circle. Use `xs` for actions inside list rows and for close buttons in
dialogs, toasts, tags and banners, where it presses a little deeper (0.93) so the response still
reads at that size.

<ComponentPreview name="icon-button-dense" align="stretch" />

### Error tone

`tone="error"` works with every variant and turns the focus ring the error colour. Keep it for
actions that delete or revoke something, and confirm the action when it cannot be undone.

<ComponentPreview name="icon-button-error" />

### Toggle

`IconToggleButton` keeps a selected state and announces it with `aria-pressed`. It comes in `ghost`
(the default) and `soft`; both take the primary soft tint when selected. Pass `selectedIcon` to
swap the glyph, such as an outlined heart for a filled one, so the state does not rest on colour
alone. Keep the `aria-label` the same in both states; the pressed state already tells assistive
technology which one is active.

<ComponentPreview name="icon-button-toggle" />

### Async actions

When `onPress` returns a promise, the button sets `isPending` until it settles. The icon is
replaced by a spinner after 300 ms, repeat presses are ignored, focus stays on the button and screen
readers hear the pending label.

<ComponentPreview name="icon-button-async" />

### As a link

`IconButtonLink` renders an anchor with the same styles. Use it for navigation, such as a help
link in a header or an external profile. Say in the label when it opens a new tab.

## API

### IconButton

| Prop         | Type                                              | Default                                   |
| ------------ | ------------------------------------------------- | ----------------------------------------- |
| `aria-label` | `string`                                          | required                                  |
| `icon`       | `ReactNode`                                       | required                                  |
| `variant`    | `'solid' \| 'soft' \| 'outline' \| 'ghost'`       | `'ghost'`                                 |
| `tone`       | `'primary' \| 'neutral' \| 'error'`               | `'primary'` for `solid`, else `'neutral'` |
| `size`       | `'xs' \| 'sm' \| 'md' \| 'lg'`                    | `'md'`                                    |
| `onPress`    | `(event: PressEvent) => void \| Promise<unknown>` |                                           |
| `isPending`  | `boolean`                                         | automatic                                 |
| `isDisabled` | `boolean`                                         | `false`                                   |
| `labels`     | `Partial<IconButtonLabels>`                       |                                           |
| `ref`        | `Ref<HTMLButtonElement>`                          |                                           |

Every other [React Aria Button](https://react-aria.adobe.com/Button) prop is passed through, so an
`IconButton` works as the trigger of a menu, popover, dialog or tooltip. The colours are Button's;
see its [variant table](/docs/components/actions/button#button).

### IconToggleButton

| Prop              | Type                            | Default   |
| ----------------- | ------------------------------- | --------- |
| `aria-label`      | `string`                        | required  |
| `icon`            | `ReactNode`                     | required  |
| `selectedIcon`    | `ReactNode`                     | `icon`    |
| `isSelected`      | `boolean`                       |           |
| `defaultSelected` | `boolean`                       | `false`   |
| `onChange`        | `(isSelected: boolean) => void` |           |
| `variant`         | `'soft' \| 'ghost'`             | `'ghost'` |
| `size`            | `'xs' \| 'sm' \| 'md' \| 'lg'`  | `'md'`    |
| `isDisabled`      | `boolean`                       | `false`   |
| `ref`             | `Ref<HTMLButtonElement>`        |           |

Every other [React Aria ToggleButton](https://react-aria.adobe.com/ToggleButton) prop is passed
through, including `id` inside a `ToggleButtonGroup`.

| Variant | Unselected                        | Selected                               |
| ------- | --------------------------------- | -------------------------------------- |
| `ghost` | no fill, `on-surface` icon        | `primary-soft` fill, `on-primary-soft` |
| `soft`  | `neutral-soft` fill, `on-surface` | `primary-soft` fill, `on-primary-soft` |

### IconButtonLink

The same style props, `aria-label`, `icon` and `ref`, plus every
[React Aria Link](https://react-aria.adobe.com/Link) prop, such as `href`, `target`,
`routerOptions` and `isDisabled`.

### Data attributes

`data-variant`, `data-tone`, `data-size`, `data-pending`, `data-selected`, `data-hovered`,
`data-pressed`, `data-focus-visible`, `data-disabled`, and `data-reduced-motion` when `DSProvider`
sets `motion` to `reduced` or `disabled`. Parts: `data-slot="icon-button"` or
`"icon-toggle-button"`, `"icon"`, `"pending"`.

### Labels

Text the icon button writes on its own. Pass `labels` to one `IconButton`, or set them for every
icon button with `<DSProvider labels={{ iconButton: { … } }}>`.

| Key       | Default   | Used for                                   |
| --------- | --------- | ------------------------------------------ |
| `pending` | `Loading` | the accessible name of the pending spinner |

## Accessibility

- Built on React Aria `Button`, `ToggleButton` and `Link`: Enter and Space activate them, and press
  events normalise mouse, touch and keyboard.
- `aria-label` is required by the types. Toggles keep one label and expose their state with
  `aria-pressed`.
- While pending, the button stays focusable, its name gains the pending label and a progress bar is
  announced, so focus never jumps.
- On coarse pointers `xs`, `sm` and `md` extend their hit area to 48px.
- The press scale follows `prefers-reduced-motion` and `DSProvider`'s `motion`.
- Contrast is checked with axe in light, dark and RTL by `icon-button.test.tsx`.
