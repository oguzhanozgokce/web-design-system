## Usage

```tsx

```

## Examples

### Variants

`variant` says how much ink a button uses. `solid` is the main action on a screen and the default.
`soft` is a translucent fill for secondary actions. `outline` adds a hairline border and suits
actions next to a solid one. `ghost` has no fill until it is hovered and suits toolbars, table rows
and quiet links to another step.

<ComponentPreview name="button-variants" />

### Tones

`tone` picks the colour role that paints the variant: `primary`, `neutral` or `error`. It defaults
to `primary` for `solid` and to `neutral` for the other variants, so only the main action carries
the accent and every quieter action stays grey. `error` is for actions that delete or revoke
something; its focus ring turns the error colour too. Pair a solid error button with a confirmation
step.

<ComponentPreview name="button-tones" />

### Sizes

`md` (40px) is the default. `sm` (32px) suits dense tables, toolbars and filter bars. `lg` (48px)
suits marketing pages and single-action screens. Every size is a pill and scales down slightly
while pressed: 0.98 at `sm`, 0.97 at `md`, 0.96 at `lg`.

<ComponentPreview name="button-sizes" />

### Icons

`startIcon` and `endIcon` take any icon and size it to the button: 16px at `sm` and `md`, 20px at
`lg`. Flip directional icons in RTL with `rtl:-scale-x-100`.

<ComponentPreview name="button-icons" />

### Async actions

When `onPress` returns a promise, the button sets `isPending` until it settles. Repeat presses are
ignored, focus stays on the button and screen readers hear the pending label. The spinner appears
only after 300 ms, so fast actions never flash.

<ComponentPreview name="button-async" />

### As a link

`ButtonLink` renders an anchor with the same styles. It navigates through `DSProvider`'s router, so
locale prefixes keep working. When it opens a new tab, say so in its name, for example with a
visually hidden "(opens in a new tab)".

## API

### Button

| Prop         | Type                                              | Default                                   |
| ------------ | ------------------------------------------------- | ----------------------------------------- |
| `variant`    | `'solid' \| 'soft' \| 'outline' \| 'ghost'`       | `'solid'`                                 |
| `tone`       | `'primary' \| 'neutral' \| 'error'`               | `'primary'` for `solid`, else `'neutral'` |
| `size`       | `'sm' \| 'md' \| 'lg'`                            | `'md'`                                    |
| `fullWidth`  | `boolean`                                         | `false`                                   |
| `startIcon`  | `ReactNode`                                       |                                           |
| `endIcon`    | `ReactNode`                                       |                                           |
| `onPress`    | `(event: PressEvent) => void \| Promise<unknown>` |                                           |
| `isPending`  | `boolean`                                         | automatic                                 |
| `isDisabled` | `boolean`                                         | `false`                                   |
| `labels`     | `Partial<ButtonLabels>`                           |                                           |

Every other [React Aria Button](https://react-aria.adobe.com/Button) prop is passed through.

| Variant × tone    | Rest                                     | Hover                   |
| ----------------- | ---------------------------------------- | ----------------------- |
| `solid` `primary` | `primary-solid` fill, `on-primary-solid` | `primary-solid-hover`   |
| `solid` `neutral` | `inverse-surface` fill                   | `inverse-surface-hover` |
| `solid` `error`   | `error-solid` fill, `on-error-solid`     | `error-solid-hover`     |
| `soft` `primary`  | `primary-soft` fill, `on-primary-soft`   | `primary-soft-hover`    |
| `soft` `neutral`  | `neutral-soft` fill, `on-surface`        | `neutral-soft-hover`    |
| `soft` `error`    | `error-soft` fill, `on-error-soft`       | `error-soft-hover`      |
| `outline` `*`     | 1px border, text in the tone             | the tone's soft fill    |
| `ghost` `*`       | no fill, text in the tone                | the tone's soft fill    |

Solid fills keep their saturated colour in dark mode. A disabled button keeps its colours at half
opacity with a `not-allowed` cursor.

### ButtonLink

The same style props plus every [React Aria Link](https://react-aria.adobe.com/Link) prop, such as
`href`, `target` and `routerOptions`.

### Data attributes

`data-variant`, `data-tone`, `data-size`, `data-pending`, `data-hovered`, `data-pressed`,
`data-focus-visible`, `data-disabled`. Parts: `data-slot="content"`, `"label"`, `"start-icon"`,
`"end-icon"`, `"pending"`.

### Labels

Text the button writes on its own. Pass `labels` to one button, or set them for every button with
`<DSProvider labels={{ button: { … } }}>`.

| Key       | Default   | Used for                                   |
| --------- | --------- | ------------------------------------------ |
| `pending` | `Loading` | the accessible name of the pending spinner |

## Accessibility

- Built on React Aria `Button`: Enter and Space activate it, and press events normalise mouse,
  touch and keyboard.
- The focus ring is a 2px outline with a 2px offset, drawn only for keyboard focus.
- While pending, the button stays focusable and announces a progress bar, so focus never jumps.
- The press scale follows `prefers-reduced-motion`.
- `DSProvider motion="reduced"` also removes press scaling; `motion="disabled"` removes pending
  fades and transitions as well.
- Contrast is checked with axe in light, dark and RTL by `button.test.tsx`.
