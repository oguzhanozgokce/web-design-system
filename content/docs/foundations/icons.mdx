Components use Material Symbols Rounded as inline SVGs. They inherit text colour and scale in `em`.

<IconSpecimen />

## Add an icon

```tsx
import { AddIcon } from '@/lib/ds/icons';

<Button startIcon={<AddIcon />}>New</Button>;
```

Icon slots also accept your own SVG components. Use `IconButton` with an `aria-label` for icon-only actions.

## Replace built-in glyphs

```tsx
import { ChevronDown } from 'lucide-react';

<DSProvider icons={{ chevronDown: ChevronDown }}>
  {children}
</DSProvider>
```

Components read replacements through `useIcons()`. Mirror directional icons in RTL;
keep symbols such as add and check unchanged.
