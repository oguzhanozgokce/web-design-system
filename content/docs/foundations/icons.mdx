---
title: Icons
description: The glyphs components draw themselves, and how to replace them.
---

Components draw a small set of Material Symbols Rounded glyphs: chevrons, check, close, search,
calendar and so on. They are inline SVGs generated by `scripts/generate-icons.ts`, sized in `em`,
so they follow the font size and inherit `currentColor`.

```tsx
import { AddIcon } from '@/lib/ds/icons';

<Button startIcon={<AddIcon />}>New</Button>;
```

Any icon works as `startIcon`: an SVG component, a Material Symbols font glyph or an image. The
button sizes it.

## Replacing glyphs

```tsx
import { ChevronDown } from 'lucide-react';

<DSProvider icons={{ chevronDown: ChevronDown }}>
```

Components read glyphs with `useIcons()`, the web counterpart of `DSTheme.icons`.
