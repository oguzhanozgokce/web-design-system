Components install as source through the shadcn CLI. Start with **React 19, TypeScript and
Tailwind CSS 4**, plus an `@/*` alias pointing to your source root. Next.js is optional.

## Start the local registry

Clone the repo using its [setup guide](https://github.com/oguzhanozgokce/web-design-system#run-the-catalogue).
The catalogue requires Node.js 24 or newer. In the registry checkout, run:

```bash
npm ci
npm run registry:build
npm run dev
```

In your **consuming app's terminal**, set the origin printed by Next.js:

```bash
export DS_REGISTRY_URL=http://localhost:3000
```

Rebuild registry JSON after changing installable files. You can put the origin directly in
`components.json` instead of setting an environment variable in every terminal.
A GitHub repository URL is not a registry endpoint.

## Set up your app

<Steps>
<Step>

### Point the project at the registry

Merge these entries into your `components.json`; keep other registries and aliases.
For Vite or another client-only app, use `rsc: false` and your actual stylesheet path, such as `src/index.css`.

```json title="components.json"
{
  "$schema": "https://ui.shadcn.com/schema.json",
  "style": "new-york",
  "tsx": true,
  "rsc": true,
  "tailwind": { "css": "app/global.css", "baseColor": "neutral", "cssVariables": true },
  "aliases": {
    "components": "@/components",
    "ui": "@/components/ds",
    "lib": "@/lib/ds",
    "hooks": "@/hooks/ds",
    "utils": "@/lib/ds/utils"
  },
  "registries": {
    "@ds": "${DS_REGISTRY_URL}/r/{name}.json"
  }
}
```

</Step>
<Step>

### Install the theme

<InstallCommand name="theme" />

Import it after Tailwind in the global stylesheet:

```css title="app/global.css"
@import 'tailwindcss';
@import '../styles/ds/theme.css';
```

The theme installs at the project root. From `src/app/global.css`, use `../../styles/ds/theme.css`;
from `src/index.css`, use `../styles/ds/theme.css`. See [Theming](/docs/foundations/theming) to change your brand.

</Step>
<Step>

### Wrap the app in DSProvider

<InstallCommand name="ds-provider" />

`DSProvider` connects locale, navigation, labels, icons and motion:

```tsx title="app/providers.tsx"
'use client';

import type { ReactNode } from 'react';
import { DSProvider } from '@/components/ds/ds-provider';

export function Providers({ children }: { children: ReactNode }) {
  return <DSProvider locale="en">{children}</DSProvider>;
}
```

Wrap your app in `Providers` and import the stylesheet at its entry point. Match document `lang`
and `dir` to the locale. Connect a router with `navigate={(href) => router.push(href)}`.

</Step>
<Step>

### Add components

<InstallCommand name="button" />

The CLI installs dependencies and follows your aliases: UI in `components/ds`, helpers in
`lib/ds`, hooks in `hooks/ds`. Keep the installed `licenses/ds/LICENSE` and `licenses/ds/NOTICE`
when redistributing source.

```tsx
import { Button } from '@/components/ds/button';

export function SaveAction() {
  return <Button>Save</Button>;
}
```

</Step>
</Steps>

## Update installed source

Review `npx shadcn@4.23.0 add @ds/button --diff` before updating a customised copy. Keep local
changes under version control and review any overwrite. This pre-1.0 registry does not update
installed components automatically.

## Publishing a registry

`npm run build` exports the catalogue and `/r/*.json` together. A future deployment can use the
same configuration with its hosted origin. Use `shadcn@4.23.0`, the CLI version verified here.
