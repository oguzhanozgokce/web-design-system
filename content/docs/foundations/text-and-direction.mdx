## Locale and direction

`DSProvider locale` controls dates, numbers, calendars and React Aria announcements.
It does **not** translate component labels.

Set the document's `lang` and `dir` to match the locale. The components use logical spacing
(`ms-`, `pe-`, `text-start`) and mirror directional arrows. Try the **LTR / RTL** switch on any preview.

## Labels with values

Templates accept placeholders or a function. Values arrive formatted for the locale:

```tsx
<Select labels={{ selectedCount: ({ count }) => `${count} items selected` }} />
```

Connect your translation library inside that function when you need plural rules.
Keep translated strings in your app; the library does not ship a translation catalogue.
