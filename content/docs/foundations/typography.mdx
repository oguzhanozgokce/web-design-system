Use your app's font with Tailwind sizes and weights **400, 500 and 600**.
Keep letter spacing normal at 16px and below; use `tracking-tight` for headings at 20px and above.

## Component reference

| Role                              | Classes                                               | Size / line |
| --------------------------------- | ----------------------------------------------------- | ----------- |
| Control label (button, tab, menu) | `text-sm font-medium`                                 | 14 / 20     |
| Small control (chip, tag, badge)  | `text-xs font-medium`                                 | 12 / 16     |
| Large control                     | `text-base font-medium`                               | 16 / 24     |
| Field value                       | `text-base pointer-fine:text-sm`                      | 16 → 14     |
| Field label                       | `text-sm font-medium text-on-surface`                 | 14 / 20     |
| Description and helper text       | `text-xs text-on-surface-variant`                     | 12 / 16     |
| Error                             | `text-xs text-error`                                  | 12 / 16     |
| Body in cards and overlays        | `text-sm text-on-surface-variant`                     | 14 / 20     |
| Card title                        | `text-sm font-semibold text-on-surface`               | 14 / 20     |
| Dialog title                      | `text-base font-semibold`                             | 16 / 24     |
| Headings 1 to 4                   | `text-2xl` to `text-base font-semibold`               | 24 to 16    |
| Display                           | `text-4xl` to `text-6xl font-semibold tracking-tight` | 36 to 60    |

Field values are 16px on touch screens, so iOS does not zoom into a focused input, and 14px with a
fine pointer. Headings of 20px and more add `tracking-tight`.
