## Use the export

**In your app:** replace the installed `styles/ds/tokens.css` with the builder's CSS export.
**In this repository:** save the config below and run `npm run generate`.

```json title="tokens/config.json"
{
  "seed": "#5B4BFF",
  "style": "vibrant",
  "surfaces": "neutral",
  "spec": "2025",
  "platform": "phone"
}
```

| Palette style | Result                                    |
| ------------- | ----------------------------------------- |
| `vibrant`     | Saturated accents; this catalogue's style |
| `tonal-spot`  | Calm, lower-chroma accents                |
| `expressive`  | Shifted hues                              |
| `fidelity`    | Containers close to the seed              |
| `neutral`     | Nearly grey                               |
| `monochrome`  | Grey only                                 |

## Mode and contrast

Set `.light`, `.dark` or `data-theme` on the page or a section. Nested sections can use a different mode.
Components use the same roles in both modes; no `dark:` styles are needed.

```html
<html class="dark" data-contrast="high"></html>
```

`data-contrast` on `<html>` accepts `standard`, `medium` or `high`.
Without it, increased OS contrast selects `high`.

## Change colours at runtime

Use [Dynamic colour](/docs/foundations/dynamic-color) for workspace brands, user preferences or image colours.
The builder, static generator and runtime themes use the same engine.
