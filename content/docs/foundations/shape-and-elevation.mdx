## Radius reference

| Utility             | Radius | Used by                                                                   |
| ------------------- | ------ | ------------------------------------------------------------------------- |
| `rounded-control`   | full   | Buttons, icon buttons, toggles, FABs, chips, tags, badges, switches, tabs |
| `rounded-field`     | 12     | Text fields, text areas, select and combo-box triggers                    |
| `rounded-item`      | 12     | Menu, list-box and select rows                                            |
| `rounded-overlay`   | 16     | Popovers, menus, select and combo-box lists                               |
| `rounded-container` | 20     | Cards, banners, toasts, accordion surfaces                                |
| `rounded-dialog`    | 24     | Dialogs, alert dialogs, bottom and detached sheets                        |

Tailwind's standard radii remain available for small parts. `cn()` and `tv()` merge radius
families correctly; logical forms such as `rounded-s-control` also work.

## Shadows

| Utility     | Used by                                                           |
| ----------- | ----------------------------------------------------------------- |
| `shadow-xs` | Segment indicator, switch thumb, slider thumb, focused soft field |
| `shadow-sm` | Elevated cards, the FAB at rest                                   |
| `shadow-md` | Popovers, menus, select lists, tooltips, toasts                   |
| `shadow-lg` | Dialogs, sheets, the hovered FAB                                  |

Shadows add a subtle rim in dark mode. Cards and fields also use a hairline border.

## Hover, press and disabled

- **Hover** swaps the fill to its `-hover` role: `bg-primary-solid-hover`, `bg-neutral-soft-hover`.
  React Aria's `data-hovered` only appears for a real mouse, so touch never leaves a sticky hover.
- **Press** keeps the hover fill and scales the control: 0.98 at `sm`, 0.97 at `md`, 0.96 at `lg`,
  0.98 for rows. Attached groups and reduced motion skip the scale.
- **Disabled** keeps the colours and drops to `opacity-50` with `cursor-not-allowed`.
- `transition-control` times all of it: the scale over 250ms, colours, borders and shadows over
  100ms.

## Focus

`focus-ring` draws a 2px `primary` outline with a 2px offset, only for keyboard focus. Controls in
the `error` tone set `[--focus-color:var(--error)]` to ring in red. `focus-ring-inset` draws the
ring inside, for list rows, menu items and table cells. Fields show focus with a `primary` border
and a soft inner ring instead.
