## Public contracts

| Contract                   | Use                                                                                                         |
| -------------------------- | ----------------------------------------------------------------------------------------------------------- |
| State                      | `isDisabled`, `isPending`, `isSelected`                                                                     |
| Interaction                | `onPress`, `value`, `defaultValue`, `onChange`; controlled and uncontrolled                                 |
| Defaults                   | `solid` uses `primary`; quieter action variants use `neutral`; controls default to `md`                     |
| Component-specific choices | Document their own variants, such as `underline` / `pill` tabs                                              |
| Status                     | Add `success`, `warning` and `info` where meaningful                                                        |
| Async actions              | Promise-returning `onPress`, `onConfirm` or `onSubmit`; own pending state and ignore repeat triggers        |
| Icon-only actions          | `IconButton` with a required `aria-label`                                                                   |
| Styling                    | Public exports such as `buttonStyles`; no nested interactive elements                                       |
| Parts                      | `data-slot` identifies each part                                                                            |
| State selectors            | `data-variant`, `data-size`, `data-pending`, `data-selected`, plus React Aria hover, press and focus states |

## Implementation contracts

- Use semantic colours, logical directions and typed labels with English defaults.
- Registry imports use `@/registry/ds/...` so the CLI can rewrite them. Installed imports follow the consumer's aliases.
- Keep framework imports (`next/*`, `next-intl`) out of registry files. Connect routing through `DSProvider`.
- Keep only required licence headers in code. Explain decisions in documentation and commit messages.
