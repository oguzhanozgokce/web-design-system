title: Color
description: Choose colours by purpose and always pair fill with text.
---

Use semantic roles instead of raw colours. Pair each fill with its matching text role:
`bg-primary-solid text-on-primary-solid` or `bg-error-soft text-on-error-soft`.

## Choose a role

| Purpose                          | Role                                     |
| -------------------------------- | ---------------------------------------- |
| Page                             | `canvas`                                 |
| Cards and fields                 | `surface-raised`                         |
| Menus, dialogs and sheets        | `surface-overlay`                        |
| Selected pill / control thumb    | `surface-segment` / `surface-thumb`      |
| Main action and checked controls | `primary-solid` + `on-primary-solid`     |
| Quiet selection                  | `primary-soft` + `on-primary-soft`       |
| Neutral interaction              | `neutral-soft` + `on-surface`            |
| Tooltip                          | `inverse-surface` + `inverse-on-surface` |

Use `on-surface` for text on neutral layers and `on-surface-variant` for supporting text.
Hover fills use the matching `-hover` role.

## Lines and focus

| Purpose                                     | Role              |
| ------------------------------------------- | ----------------- |
| Field and outline-button border             | `outline-variant` |
| Checkbox and radio edge                     | `outline`         |
| Divider and card border                     | `outline-subtle`  |
| Modal scrim                                 | `backdrop`        |
| Focus, active links and selected indicators | `primary`         |

## Status and charts

Use `error`, `success`, `warning` and `info` for meaning, not decoration. Each has solid and soft pairs.
Disabled controls keep their colours at 50% opacity.

Multi-series charts use `chart-1` through `chart-8` in order; a single series uses `primary`.
Chart colours are fixed across seeds. Always keep labels, a legend and the [table view](/docs/components/charts/chart)
so colour is not the only way to read the data.
