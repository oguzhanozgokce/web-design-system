## Languages

Built-in strings (`Loading`, `Close`, `Previous month`, `Rows per page`) ship in the 18 languages
the apps support: en, tr, de, fr, es, pt, it, ru, nl, pl, id, zh, ja, vi, th, uk, sw and ar.
`npm run check:ds` fails if a component's catalogue misses one.

The locale comes from `DSProvider locale`. React Aria uses it for dates, numbers, calendars and its
own announcements.

## Overriding strings

Every component keeps its strings in a `*.messages.ts` file with a namespace. Override any of them:

```tsx
<DSProvider locale="tr" messages={{ button: { pending: 'Kaydediliyor' } }}>
```

## Right to left

The library uses logical properties only: `ms-`, `pe-`, `inset-s-`, `rounded-s-`, `border-e`,
`text-start`. Physical ones (`ml-`, `left-`, `text-left`) fail `check:ds`. Set `dir="rtl"` on
`<html>` for Arabic and the layout mirrors.

Directional icons, such as arrows, need `rtl:-scale-x-100`. Icons that mean the same in both
directions, such as a plus or a check, do not.

Every preview on this site has an LTR/RTL switch and a locale picker.
