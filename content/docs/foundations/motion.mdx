Use motion to connect an action to its result. Keep ordinary controls quick and let the user's preference lead.

```tsx
<DSProvider motion="reduced" motionProfile="productive">
  {children}
</DSProvider>
```

`productive` uses calmer springs; `expressive` is the default.
Place the provider around a flow-content region, not directly inside a table, list or select.

## Timing reference

| Change                  | Timing / curve                         |
| ----------------------- | -------------------------------------- |
| Fill, border and shadow | 100ms · `ease-out`                     |
| Press scale             | 250ms · `ease`                         |
| Popover                 | 150ms in / 100ms out · `ease`          |
| Dialog                  | 250ms in / 100ms out · `ease-out-quad` |
| Sheet                   | 250ms in / 200ms out · `ease-fluid`    |
| Switch thumb            | 300ms · `ease-fluid`                   |
| Toast                   | 350ms · `ease-fluid`                   |

`ease-fluid` is `cubic-bezier(0.32, 0.72, 0, 1)`;
`ease-out-quad` is `cubic-bezier(0.25, 0.46, 0.45, 0.94)`.

## Build on the shared motion

- Use `transition-control` for control states.
- Use `motionEasings`, `motionDurations` and `fluidTween()` from `@/lib/ds/motion` in JavaScript.
- Use `spatialSpring()` for gestures that carry velocity, such as sheet dragging. Use `effectSpring()` for visual effects.
- Read `useMotionPreference()` before custom movement. CSS-only effects also need `motion-reduce:`.

<details>
<summary>Overlay keyframes and CSS scopes</summary>

React Aria's `data-entering` and `data-exiting` drive the shared keyframes:

| Utility                                      | Purpose                            |
| -------------------------------------------- | ---------------------------------- |
| `animate-ds-popover-in` / `-out`             | Scale and move toward the trigger  |
| `animate-ds-dialog-in` / `-out`              | Dialog scale and fade              |
| `animate-ds-sheet-in-{side}` / `-out-{side}` | Slide from a logical edge          |
| `animate-ds-fade-in` / `-out`                | Scrims and reduced-motion fallback |
| `animate-ds-spin`, `-shimmer`, `-pulse`      | Progress and placeholders          |

Generated spring curves are also available as `--ds-ease-spatial` and `--ds-duration-spatial`.
The provider renders a `display: contents` scope with `data-ds-motion` and `data-motion-profile`.
It handles shared press effects; custom spatial transitions still need to read the preference.

</details>
